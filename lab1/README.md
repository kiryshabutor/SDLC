# Лабораторная работа №1 — вариант 4

Desktop-приложение на Go и Fyne: пользователь вводит вес на Земле, а
программа показывает вес на планетах Солнечной системы.

## Структура проекта

```text
cmd/weight-calculator/  — точка входа
internal/model/         — данные и активная модель-наблюдатель
internal/service/       — проверка ввода и расчёты
internal/controller/    — обработка действий пользователя
internal/view/          — окна и элементы Fyne
```

Поток данных: `View → Controller → Service → Model → View`.

## Запуск

```bash
go mod tidy
go run ./cmd/weight-calculator
```

В Linux для Fyne нужны системные библиотеки GLFW/X11 и OpenGL. Например, на
Ubuntu/Debian можно установить их так:

```bash
sudo apt install gcc libgl1-mesa-dev xorg-dev
```

## Использование

1. Нажать «Ввести данные».
2. Ввести положительный вес в килограммах (например, `70` или `70,5`).
3. Нажать «Рассчитать».

Последнее корректное значение автоматически подставляется при следующем
открытии окна ввода.
