## Сборка изображений

```bash
./uml/render.sh   # нужен Docker и plantuml.jar (переменная PLANTUML_JAR)
```

Скрипт запускает PlantUML в образе `sysml-render` (Java 21 + Graphviz, см. `srs/sysml/tools/Dockerfile`) и кладёт PNG в `uml/images/`. Высокие узкие изображения скрипт дополняет белыми полями до отношения высоты к ширине 1,4.

Чтобы в отчёте при ширине рисунка 12 см заглавные буквы были не ниже 2,5 мм (СТП), все надписи набраны кеглем 16, а каждая диаграмма не шире 820 px при 150 dpi. Поэтому крупные диаграммы разделены на части с буквами a, b, c (ADR-0010, правило 6). В VS Code диаграммы можно просматривать расширением PlantUML (Alt+D).
