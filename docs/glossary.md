# Глоссарий проекта

Для веб-сервиса «Охотник за скидками в Steam», релиз R1

Подготовил Бутор К. П., гр. 450503 · Версия 1.0 · 08.11.2026

Глоссарий фиксирует термины предметной области, модели прецедентов и дизайна, чтобы SRS, SDD, ADR, UML-модель (`uml/`) и код использовали одни и те же слова в одном значении. Термины, которые не переводятся (SRS, SDD, ADR, View и т. п.), описаны в [terminology.md](terminology.md). Колонка «Где используется» указывает документ или элемент модели, где термин появляется впервые или играет ключевую роль; колонка «В коде» показывает имя в программе, если оно есть.

## Предметная область

| Термин | Определение | Где используется | В коде |
|--------|-------------|------------------|--------|
| Игра | Приложение, продаваемое в магазине Steam и однозначно определяемое appid | SRS 1.3, UC-04, UC-05 | `domain.Game` |
| appid | Числовой идентификатор игры в Steam, например 1245620 для Elden Ring | SRS 1.3, UC-05 | `AppID` |
| Ссылка на игру | Адрес страницы игры вида `store.steampowered.com/app/<appid>/...`, из которого извлекается appid | REQ-FUNC-009, UC-05 | `domain.ParseAppRef` |
| Регион | Страна магазина Steam (параметр `cc`): BY, RU, KZ, US, PL. Определяет цену, валюту и доступность игры | SRS 1.3, UC-15 | `domain.Region` |
| Пара (игра, регион) | Единица опроса цен: одна игра в одном регионе. Каждая пара опрашивается один раз за цикл, сколько бы пользователей её ни отслеживали | REQ-FUNC-017, AD-01 | `price_state` |
| Итоговая цена | Цена игры в регионе с учётом текущей скидки, в минимальных единицах валюты (3999 = 39,99) | REQ-FUNC-018 | `Price.Final` |
| Обычная цена | Цена игры без скидки | SRS 1.3 | `Price.Initial` |
| Скидка | Разница между обычной и итоговой ценой в процентах (0–99) | REQ-FUNC-015 | `Price.DiscountPct` |
| Доступность | Особое состояние игры в регионе: продаётся, недоступна в регионе, бесплатная, не вышла | REQ-FUNC-016, SM-01 | `domain.Availability` |
| История цен | Последовательность записей (пара, цена, скидка, время, источник), создаваемых только при изменении цены | REQ-FUNC-018, ADR-0004 | `price_history` |
| Исторический минимум | Наименьшая известная итоговая цена пары по всей истории региона | REQ-FUNC-023 | `hist_low_price` |
| Мировые скидки | Даты и проценты прошлых распродаж в Steam по данным ITAD для США, без цен | REQ-FUNC-024 | `world_sales` |
| Вишлист | Список игр, которые пользователь отслеживает в Системе (до 500 игр) | SRS 1.3, UC-08 | `wishlist_items` |
| Вишлист Steam | Список желаемого в профиле Steam, который можно импортировать | REQ-FUNC-010, UC-06 | `WishlistSource` |
| Элемент вишлиста | Пара «пользователь, игра» с условием уведомления и последней уведомлённой ценой | DV-004, SM-01 | `WishlistItem` |
| Условие уведомления | Правило срабатывания уведомления: любая скидка, скидка не менее N %, цена не выше X, исторический минимум | REQ-FUNC-015, UC-07 | `domain.Condition` |
| Уведомление | Сообщение пользователю о том, что его условие выполнено для игры | REQ-FUNC-025, UC-13 | `notifications` |
| Защита от повторов | Правило, по которому уведомление по игре не создаётся снова, пока итоговая цена не изменится | REQ-FUNC-026, SM-01 | `last_notified_price` |
| Дайджест | Одно письмо или одно сообщение Telegram со всеми уведомлениями пользователя за цикл | REQ-FUNC-027-2 | `kind = digest` |
| Центр уведомлений | Страница сайта со списком уведомлений за 90 дней | REQ-FUNC-028, UC-14 | `GET /notifications` |
| Канал доставки | Способ доставки дайджеста: email или Telegram | REQ-FUNC-006-2, ADR-0009 | `Notifier` |
| Код привязки Telegram | Одноразовый код (15 минут), который пользователь отправляет боту для привязки аккаунта | REQ-FUNC-031, UC-11 | `telegram_link` |

## Процессы и механизмы

| Термин | Определение | Где используется | В коде |
|--------|-------------|------------------|--------|
| Цикл опроса | Однократный проход фонового обработчика по всем отслеживаемым парам: получение цен, запись истории, проверка условий, формирование дайджестов | REQ-FUNC-017, UC-12, AD-01 | `poll_cycles` |
| Период опроса | Интервал между плановыми циклами, по умолчанию 3 часа (от 1 до 24 ч) | REQ-FUNC-017 | `POLL_INTERVAL` |
| Ручная проверка | Внеочередной цикл только по парам одного пользователя, не чаще раза в 10 минут | REQ-FUNC-020, UC-10 | `jobs.kind = check` |
| Тестовый режим | Режим демонстрации, в котором Steam заменён имитированным источником цен | REQ-FUNC-030, UC-16 | `TEST_MODE` |
| Пакетный запрос | Запрос `appdetails` с несколькими appid одного региона | DV-007, DV-015 | `PriceSource.Prices` |
| Бюджет запросов | Статически поделённый лимит запросов к Steam: 120 у обработчика и 30 у API за 5 минут | REQ-INT-007, ADR-0006 | `platform.RateLimiter` |
| Блокировка цикла | Рекомендательная блокировка PostgreSQL, не дающая двум циклам идти одновременно | ADR-0006 | `pg_advisory_lock(42)` |
| Outbox | Таблица исходящих писем и сообщений, из которой фоновый обработчик отправляет их с повторами | ADR-0007, SM-02 | `email_outbox` |
| Задание | Запись в очереди `jobs` (ручная проверка, импорт), которую API ставит, а обработчик выполняет | DV-009 | `jobs` |

## Роли и внешние системы (актёры)

| Термин | Определение | Где используется |
|--------|-------------|------------------|
| Гость | Неавторизованный посетитель сайта | UC-01…UC-03 |
| Пользователь | Зарегистрированный и вошедший в Систему игрок, ожидающий скидок | UC-04…UC-15 |
| Разработчик | Разворачивает и сопровождает Систему, проводит демонстрацию в тестовом режиме | UC-16 |
| Время | Абстрактный актёр-таймер, который инициирует плановый цикл опроса раз в период опроса | UC-12 |
| Steam | Магазин Valve: Store API (поиск, цены) и Web API (вишлист, профили) | UC-04…UC-06, UC-12 |
| IsThereAnyDeal (ITAD) | Сторонний сервис истории цен; используется только для регионов US и PL и блока мировых скидок | UC-09, UC-17 |
| Почтовый сервер | SMTP-сервер, доставляющий письма пользователю | UC-01, UC-13 |
| Telegram | Telegram Bot API: приём кода привязки и доставка дайджестов | UC-11, UC-13 |
