## Описание проекта

Приложение предназначено для расчёта веса человека на планетах Солнечной
системы. Пользователь вводит свой вес на Земле, после чего программа
вычисляет и отображает соответствующий вес на Меркурии, Венере, Марсе,
Юпитере, Сатурне, Уране и Нептуне с учётом различий силы тяжести.

Программа имеет графический интерфейс. Ввод исходных данных выполняется в
отдельном окне, а результаты расчёта отображаются на главной форме. Последнее
корректно введённое значение веса сохраняется и автоматически восстанавливается
при следующем открытии окна ввода.

## Основной функционал

- ввод веса человека на Земле;
- расчёт веса для планет Солнечной системы;
- отображение результатов в графическом интерфейсе;
- проверка корректности введённых данных;
- обработка пустого, нечислового, нулевого и отрицательного значений;
- сохранение последнего корректного значения веса;
- восстановление сохранённого значения при повторном открытии окна ввода;
- разделение компонентов приложения по архитектуре MVC.

## Архитектура

Приложение построено с использованием паттерна MVC:

- **Model** хранит состояние приложения и уведомляет подписчиков при его
  изменении;
- **View** формирует графический интерфейс и отображает результаты расчёта;
- **Controller** принимает действия пользователя и связывает интерфейс с
  логикой приложения;
- **Service** содержит проверку входных данных и расчёты веса на основе
  относительной силы тяжести каждой планеты.

Активная модель использует механизм наблюдателей: после изменения данных она
уведомляет представление, и интерфейс обновляет отображаемые результаты.

## Сборка и запуск

Для запуска необходимы Go и системные зависимости Fyne.

В Ubuntu/Debian выполните:

```bash
sudo apt update
sudo apt install gcc libgl1-mesa-dev xorg-dev
```

Затем в каталоге проекта выполните:

```bash
go mod tidy
go run ./cmd/weight-calculator
```

Для сборки исполняемого файла:

```bash
go build ./...
```

Для запуска автоматических тестов:

```bash
go test ./...
```

## Использование

1. Нажмите кнопку «Ввести данные».
2. Введите положительный вес в килограммах, например `70` или `70,5`.
3. Нажмите кнопку расчёта.
4. Просмотрите рассчитанный вес для каждой планеты.
